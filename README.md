# Agent Engineering

A hands-on Python course on building AI agents from the ground up.

We start by constructing a simple language model, then build an embeddings
model, explore vector stores and retrieval-augmented generation (RAG), and
finally put it all together into working agents.

## Course outline

The course is being built step by step. Modules will be added here as they are written.
