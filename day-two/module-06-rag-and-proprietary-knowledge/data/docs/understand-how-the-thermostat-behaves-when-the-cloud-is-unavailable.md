# Understand how the thermostat behaves when the cloud is unavailable

## When the thermostat cannot reach the cloud

The thermostat can lose contact with the Dormouse cloud even when its Wi-Fi connection is working. If this happens, its display shows E-110. The app shows the same code and can notify you about it.

E-110 means the thermostat cannot reach the Dormouse cloud. It does not mean the thermostat has stopped running your heating schedule.

## What continues to work

While the cloud is unavailable, the thermostat keeps running its schedules. It continues to control the heating using the schedule already stored on the thermostat.

The thermostat's local heating controls also remain available. You can turn the dial to change the target temperature. A manual temperature change lasts until the next schedule period starts.

## What happens to app changes

Changes you make in the app cannot reach the thermostat while it is disconnected from the cloud. They wait until the thermostat reconnects.

This includes changes such as adjusting the target temperature or changing a schedule. The thermostat continues using its current settings while it is offline. After it reconnects, waiting app changes can be delivered to it.

## Check the connection

If the display shows E-110, check that your router is connected to the internet. The thermostat needs an internet connection to reach the Dormouse cloud.

When the thermostat reconnects, it can receive app changes that were waiting. Until then, rely on the thermostat's existing schedule or make a temporary adjustment at the dial.

## Wi-Fi and cloud connection symbols

The Wi-Fi symbol with a cross means the thermostat is not connected to Wi-Fi. E-110 has a different meaning: the thermostat cannot reach the Dormouse cloud.

If you see E-110, follow the guidance for that code and check your router's internet connection. If the display instead shows a Wi-Fi symbol with a cross, the thermostat is not connected to Wi-Fi.

## If the problem continues

The app shows the same error code as the thermostat. You can also choose to receive notifications about thermostat errors.

For help with a continuing connection problem, contact Dormouse support in the app under Help > Contact support. While the thermostat cannot reach the cloud, it continues running its schedules, but app changes wait for the connection to return.
