# Android app: Schedule screen guide

## About the Schedule screen

The Schedule screen lets you choose the temperatures you want at different times of day. Each day can have up to six periods. A period has a start time and a target temperature, and lasts until the next period starts.

You can set schedules in the Dormouse app for Android and iOS, or in the web dashboard. The steps and menu paths in this guide apply to all three.

The thermostat runs its schedule automatically. To see today's periods on the thermostat, press the dial to open the menu, then choose Menu > Schedule. You can view today's schedule on the thermostat, but you must use the app or web dashboard to change it.

## Open the Schedule screen

Open the Dormouse app or web dashboard and go to the Schedule tab. The screen shows the days you can choose from.

Select the day you want to set up. Check that you have chosen the correct day before changing its periods, especially when you are editing schedules for several days.

## Understand schedule periods

A schedule is made up of periods. Each period contains:

- A start time.
- A target temperature.

The target temperature for a period applies from its start time until the next period begins. The last period of the day continues until the next day's first period starts.

You can set up to six periods for each day. Use periods to describe the temperature you want at different times. For example, a period can start in the morning and another can start later in the day.

## Choose a day

1. Open the Schedule tab.
2. Select the day you want to edit.
3. Review the periods shown for that day.
4. Change the periods as needed, or copy periods from another day.

Each day can have its own schedule. Changing one day's periods does not require you to change the other days. If several days should use the same periods, use Copy day rather than entering them again.

## Set up periods

For the selected day, set the start time and target temperature for each period you need. Add periods until the day reflects the times and temperatures you want, up to a maximum of six periods.

A new period starts at its chosen start time and replaces the target temperature of the period before it. Check the start times and temperatures together so the schedule matches your intended pattern through the day.

You do not need to create six periods. Use only the number needed for that day's schedule.

## Copy a day's periods

Use Copy day to apply one day's periods to other days.

1. Set up the periods on the day you want to copy.
2. Choose Copy day.
3. Select the other day or days that should use the same periods.
4. Confirm the copy in the app or web dashboard.

Copy day is useful when several days share a schedule. After copying, select each day to check its periods. You can then make changes to an individual day without changing the others.

## Check the schedule

Before leaving the Schedule screen, review each day you have changed. Check that:

- Each day has no more than six periods.
- Each period has the intended start time and target temperature.
- Copied periods are on the intended days.
- Days that need a different schedule still have their own periods.

The thermostat follows the schedule for the current day. On the thermostat, Menu > Schedule shows today's periods. Schedule changes are made in the app or web dashboard.

## Schedule and manual temperature changes

A temperature change made by hand lasts until the next schedule period starts. When that period begins, the thermostat returns to the target temperature set in the schedule.

A schedule period continues until the next period starts. Check the next start time when you are deciding how long a target temperature should apply.
