# Firmware 3.5 release notes

Firmware 3.5 was released on 1 December 2025.

## Update retry

If a firmware update fails, the thermostat shows E-510, keeps its current firmware and tries the update again the next night. No action is needed.

## Low backup batteries

E-401 now appears a month before the backup batteries are expected to run out. Replace the two AA batteries behind the front cover within a month.
