# Target Temperature Change Does Not Last

A temperature you set by hand lasts until the next schedule period starts. When that period begins, the thermostat changes to the temperature set in your schedule. This is normal behaviour.

## What to expect

You can change the target temperature by turning the thermostat dial or using the Dormouse app. The target temperature can be set from 5 to 30 degrees in half-degree steps.

A manual change is temporary: it does not replace the temperature in your schedule. For example, if you raise the target temperature by hand, it returns to the scheduled temperature when the next period starts.

## Check when the next period starts

Schedules divide the day into periods. Each period has a start time and a target temperature, and lasts until the next period starts.

To see today's periods on the thermostat, press the dial to open the menu and choose Menu > Schedule. You can also view the schedule in the Schedule tab of the app or web dashboard.

Check the next period's start time and target temperature. If the manual change ends at that time, the thermostat is following its schedule.

## Keep a temperature for longer

To have the thermostat use a different temperature after the next period starts, change the schedule in the app or web dashboard:

1. Open the Schedule tab.
2. Choose the day you want to change.
3. Set the start time and target temperature for the relevant period.
4. Repeat for any other days that need a different schedule.

Each day can have up to six periods. On the thermostat, Menu > Schedule shows today's periods, but you can only change schedule periods in the app or web dashboard.

## Check for changes made elsewhere

The thermostat works with the Dormouse app and web dashboard. Most settings can be changed in any of them. If someone else in your household changes the schedule, the thermostat will follow the updated schedule when the relevant period begins.

Household members can change temperatures and schedules. The home owner can invite or remove members in Settings > Household.

## If the change ends sooner than expected

Check the schedule's period start times and target temperatures in the app or web dashboard. A manual temperature change lasts until the next period starts, even if that period begins soon after you make the change.

If the schedule looks right but the thermostat does not follow it, check whether an error code appears on the display or in the app. For example, E-110 means the thermostat cannot reach the Dormouse cloud. While disconnected, it keeps running its schedules, but changes made in the app wait until it reconnects.

For support, use Help > Contact support in the app.
