# Resolve error E-221: Humidity sensor fault

## What E-221 means

E-221 indicates a humidity sensor fault. The heating continues to work, but humidity readings disappear from the Dormouse app while the fault is present. The thermostat display and app show the same error code.

## What to expect

You can continue using the heating and changing its settings as usual. E-221 does not stop the heating from working.

Humidity readings will not appear in the app while the fault is present. The error code may also appear as an app notification if you have enabled notifications for errors in Settings > Notifications.

## Check the error in the app

1. Open the Dormouse app and check whether E-221 is still shown.
2. If you receive an error notification, use it to identify the code.
3. Check the thermostat display for the same code.

The thermostat's error code and the code shown in the app should match.

## When to contact support

Contact Dormouse support if E-221 remains for more than a day. Use Help > Contact support in the app.

## What happens while you wait

The heating keeps working while E-221 is present. Humidity readings remain unavailable in the app until the fault is resolved.
