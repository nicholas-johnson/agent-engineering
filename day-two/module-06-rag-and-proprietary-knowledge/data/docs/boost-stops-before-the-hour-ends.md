# Boost Stops Before the Hour Ends

A boost heats the home at the boost temperature for one hour. If it stops sooner than expected, check whether it was cancelled.

## Check the boost display

While a boost is running, the thermostat display shows an upward arrow. If the arrow is no longer shown, the boost is not running.

## Check whether the button was pressed again

Pressing the boost button a second time cancels the running boost. If the button was pressed again, the boost ended because it was cancelled.

## Start another boost

To start a new boost, press the boost button once. The thermostat heats at the boost temperature for one hour. The upward arrow appears while the boost is running.

Press the boost button again only if you want to cancel it before the hour ends.
