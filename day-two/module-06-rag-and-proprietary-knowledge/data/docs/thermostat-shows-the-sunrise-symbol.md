# Thermostat Shows the Sunrise Symbol

## Identify the symbol

The sunrise symbol means Warm Wake is heating ahead of a schedule period. It is not an error code. The heating is working as intended when this symbol appears.

This guide identifies the symbol and explains what to check if you think the heating is not behaving as expected. It does not describe Warm Wake's timing or how to change its settings.

## Check the thermostat display

The display shows the room temperature in large numbers and the target temperature underneath. The sunrise symbol indicates that Warm Wake is active.

If the symbol disappears, that alone does not indicate a fault. The display can dim after 20 seconds without a touch. Turn the dial to make the target temperature larger while you change it.

## Check the schedule

A schedule sets the target temperature for periods throughout the day. Each day can have up to six periods. A period starts at its listed time and lasts until the next period starts.

To view today's periods on the thermostat, press the dial to open the menu, then choose Menu > Schedule. You can view and change schedules in the Schedule tab of the app or web dashboard. On the thermostat, you can view today's periods but cannot change them.

## Check the target temperature

The target temperature is the temperature the thermostat is set to reach. It can be set from 5 to 30 degrees in half-degree steps.

Turn the dial or use the app to make a manual change. A temperature change made by hand lasts until the next schedule period starts. Check the target shown on the display and compare it with the schedule period you expect to be active.

## Check for other heating indicators

The display uses different symbols for different heating states:

| Symbol | Meaning |
|---|---|
| Sunrise | Warm Wake is heating ahead of a schedule period. |
| Flame | The thermostat is asking the boiler for heat. |
| Snowflake | Frost protection is heating the home. |
| Upward arrow | A boost is running. |
| House with an arrow | Away mode is on. |

Frost protection turns the heating on if the room falls below 5 degrees, even when the heating is off or away mode is on. It is always on and cannot be turned off.

## Check for an error code

If the display shows an error code as well as, or instead of, the sunrise symbol, check the code in the guide or in the app. The app shows the same error code as the thermostat and can notify you about it.

For example, E-110 means the thermostat cannot reach the Dormouse cloud. The thermostat keeps running its schedules, but changes made in the app wait until it reconnects. Other codes can indicate an issue with Wi-Fi, the boiler, a sensor, power or the backup batteries.

## Check the heating equipment

If the display shows the flame symbol but the home is not heating as expected, check that the boiler is switched on. If the thermostat shows E-305, check that the boiler pressure is between 1 and 1.5 bar, then check the boiler's own display for a fault.

If the thermostat shows E-312, the boiler has reported a fault of its own. Look up that fault in the boiler's manual, or contact a registered gas engineer.

## Contact support

If the symbol appears with an error code that you cannot resolve using the error-code guidance, contact Dormouse support in the app under Help > Contact support. Include the error code shown on the thermostat.

Do not treat the sunrise symbol by itself as a fault. It identifies Warm Wake; this guide does not explain its timing or settings.
