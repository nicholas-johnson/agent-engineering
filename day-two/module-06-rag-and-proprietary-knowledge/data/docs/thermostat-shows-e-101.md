# Thermostat Shows E-101

E-101 means the thermostat cannot find its Wi-Fi network. The thermostat needs a 2.4 GHz Wi-Fi network; it cannot join a 5 GHz network.

Work through the checks below in order. After each step, check whether the error has cleared. If the thermostat still shows E-101, continue to the next step.

## 1. Check the router is on

Make sure the router is switched on and has finished starting up. Check that other devices can connect to its Wi-Fi network.

If the router is off or not working, switch it on or restore its connection, then check the thermostat again.

## 2. Check that Wi-Fi is available

Check that the router is broadcasting a Wi-Fi network. If the network is not visible to other devices, check the router's Wi-Fi settings or instructions.

The thermostat must be able to find the network during pairing. Keep the thermostat and router within a range where other devices can connect reliably.

## 3. Check for a 2.4 GHz network

The thermostat can connect only to a 2.4 GHz Wi-Fi network, not a 5 GHz network. Check your router settings to confirm that it offers a 2.4 GHz network.

Some routers show separate network names for 2.4 GHz and 5 GHz. If yours does, use the 2.4 GHz network when pairing. If you are unsure which network is 2.4 GHz, check the router's instructions or settings.

## 4. Check whether the network name or password changed

If you recently changed the Wi-Fi network name or password, the thermostat may still have the old details. Pair the thermostat again so it can connect using the current network details.

To start pairing:

1. Hold the thermostat dial down for 5 seconds, until the display shows PAIR.
2. In the app, choose Add thermostat and follow the steps.
3. Keep your phone within 5 metres of the thermostat until the app says pairing has finished.

Pairing must finish within 3 minutes of PAIR appearing. If it takes longer, the display shows E-104; hold the dial down for 5 seconds and start again.

## 5. Check the result

Once pairing has finished, check that the thermostat is connected to Wi-Fi and that E-101 is no longer displayed.

If the error remains, contact Dormouse support in the app under Help > Contact support.
