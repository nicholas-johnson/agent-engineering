# iOS app: Account settings screen guide

## About this guide

This guide describes account sign-in details and the two-step verification setting in the Dormouse app for iOS. It applies to the Dormouse Thermostat with firmware 4.1.

You can also sign in to the web dashboard with your email address and password. Most settings can be changed in the app or the web dashboard. Menu paths in this guide use the same names in both.

## Sign-in details

Sign in to the Dormouse app with your email address and password. Your password must have at least 10 characters.

Use the email address associated with your Dormouse account. If you have trouble signing in, check that you entered the email address and password you use for the account.

## Reset your password

If you cannot remember your password, reset it from the sign-in screen:

1. Choose **Forgot password?**
2. Enter your email address.
3. Follow the link sent to that address to reset your password.

The reset link works for 30 minutes and can only be used once. If it has expired or has already been used, request a new link from the sign-in screen.

## Two-step verification

Two-step verification adds a 6-digit code to the sign-in process when you sign in on a new phone or browser. You enter the code as well as your password.

The code arrives by email, or from an authenticator app if you have set one up. Keep access to the method you use to receive your code when signing in on a new device.

## Turn two-step verification on

To enable two-step verification in the app, go to:

**Settings > Account > Two-step verification**

Follow the instructions on screen to turn on the setting. Once enabled, you will be asked for a code as well as your password when signing in on a new phone or browser.

## Account settings in the web dashboard

You can also sign in to the web dashboard using your email address and password. Account settings are available there as well. The path to the two-step verification setting is:

**Settings > Account > Two-step verification**

The same code requirement applies when you sign in on a new browser.

## Sign-in security

Two-step verification provides an additional step when a sign-in takes place on a new phone or browser. It does not replace your password: enter your password and the 6-digit code when asked.

If you have not set up an authenticator app, the code comes by email. A password reset link is separate from the sign-in code: the reset link is for changing your password, works for 30 minutes and can only be used once.

## Getting help

If you need help with account settings or signing in, contact Dormouse support in the app under **Help > Contact support**.
