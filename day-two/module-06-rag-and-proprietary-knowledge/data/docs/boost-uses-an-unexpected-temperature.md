# Boost Uses an Unexpected Temperature

A boost heats the home at the configured boost temperature for one hour. If the temperature during a boost is not what you expect, check the boost setting first.

## Check the configured boost temperature

The boost temperature is 21 degrees unless it has been changed. Check the setting in the app or web dashboard:

1. Open Settings > Heating > Boost temperature.
2. Check the configured temperature.
3. If needed, change it to the temperature you want.

The target temperature can be set from 5 to 30 degrees in half-degree steps.

## Start a boost again

After checking the setting, press the thermostat's boost button to start a boost. The display shows an upward arrow while the boost is running. The heating runs at the configured boost temperature for one hour.

Press the boost button again to cancel a boost.

## Allow for a manual temperature change

Turning the dial or changing the target temperature in the app makes a manual change. That change lasts until the next schedule period starts. If the target temperature you see differs from the boost temperature, check whether a manual change is in effect, then start a boost again to check its temperature.

## Check the display symbols

The upward arrow indicates that a boost is running. Other symbols have different meanings:

- The flame means the thermostat is asking the boiler for heat.
- The sunrise means Warm Wake is active.
- The snowflake means frost protection is heating.
- The house with an arrow means away mode is on.

If the upward arrow is not showing, the thermostat is not indicating that a boost is running. Press the boost button to start one.

## Check for a displayed error

If the thermostat shows an error code, the app shows the same code and can notify you about it. Follow the guidance for that code in the thermostat user guide. For example, E-305 means the boiler is not responding; check that the boiler is switched on and its pressure is between 1 and 1.5 bar, then check the boiler's own display for a fault.

## Check whether heating is available

A boost cannot make the thermostat switch the heating on while mains power is off. If E-402 is displayed, the thermostat is running on backup batteries and cannot switch the heating on. Restore mains power.

If the room falls below 5 degrees, frost protection can also turn on the heating, even when heating is off or away mode is on. Frost protection is always on.

## Contact support

If the boost temperature still seems unexpected after checking the setting and starting a boost again, contact Dormouse support in the app under Help > Contact support. Include the configured boost temperature and any error code shown on the thermostat.
