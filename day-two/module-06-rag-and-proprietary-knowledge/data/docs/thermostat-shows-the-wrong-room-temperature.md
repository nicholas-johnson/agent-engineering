# Thermostat Shows the Wrong Room Temperature

Use this guide when the room temperature shown on your Dormouse Thermostat seems incorrect. Check what the display is measuring, then look for a temperature sensor error.

## Check the displayed room temperature

The thermostat shows the room temperature in large numbers. The target temperature appears underneath. When you turn the dial, the target temperature becomes larger while you change it; this does not mean the room temperature has changed.

After 20 seconds without a touch, the display dims. Turn the dial or press it to view the display clearly.

## Compare the room and target temperatures

Check that you are reading the large room-temperature number, not the target temperature. The target temperature is the temperature the thermostat is set to reach. It can be changed by turning the dial or using the app.

A manual change to the target temperature lasts until the next schedule period starts. The schedule can be viewed in the app or web dashboard. On the thermostat, choose Menu > Schedule to see today's periods; schedule changes must be made in the app or web dashboard.

## Check for a sensor error

Look at the thermostat display for an error code. The app shows the same code and can notify you about it.

If the display shows E-217, the thermostat has detected that its temperature sensor is disconnected. This is different from a target temperature that does not match the current room temperature.

## Understand the heating response to E-217

When the temperature sensor is disconnected, the thermostat turns the heating off to be safe. Do not treat this as a normal heating setting or try to resolve it by changing the target temperature or schedule.

Contact Dormouse support to arrange a replacement. In the app, go to Help > Contact support.

## Check other displayed conditions

A symbol on the display can help explain what the thermostat is doing:

| Display indication | Meaning |
|---|---|
| Flame | The thermostat is asking the boiler for heat. |
| Sunrise | Warm Wake is heating ahead of the next schedule period. |
| Snowflake | Frost protection is heating the home. |
| Upward arrow | A boost is running. |
| Wi-Fi symbol with a cross | The thermostat is not connected to Wi-Fi. |

These indications describe heating or connection status; they do not replace the room-temperature reading.

## If the reading still seems wrong

If the display does not show E-217 but the room-temperature reading still seems incorrect, contact Dormouse support through Help > Contact support in the app. Include any error code shown on the thermostat or in the app so support can identify the reported condition.
