# E-312: Boiler reports a fault

## What E-312 means

E-312 means the boiler has reported a fault of its own. The Dormouse Thermostat has received the fault information from the boiler and displays E-312.

This is different from E-305, which means the boiler is not responding. With E-312, the boiler has reported a fault that needs to be checked using the boiler's own display and instructions.

## What can cause it

E-312 does not identify the specific boiler fault. The cause is reported by the boiler, so check the code or message on the boiler's display and look it up in the boiler's manual.

The thermostat cannot diagnose or clear the boiler's fault. Avoid treating E-312 as a thermostat fault or attempting to repair the boiler yourself.

## What to do

Follow these steps:

1. Check the boiler's own display for a fault code or message.
2. Look up that code or message in the boiler's manual and follow the instructions for it.
3. If the manual indicates that the fault needs professional attention, or you cannot resolve it using the manual, call a registered gas engineer.

## Check the thermostat display

The Dormouse Thermostat shows E-312 when the boiler reports a fault. The app shows the same error code and can notify you about it.

If you need help with the thermostat or its error display, contact Dormouse support in the app under Help > Contact support.

## Do not confuse it with E-305

E-305 means the boiler is not responding. For E-305, check that the boiler is switched on and its pressure is between 1 and 1.5 bar, then check the boiler's own display for a fault.

E-312 means the boiler has reported a fault. Check the boiler's display and manual for the specific fault, or call a registered gas engineer.
