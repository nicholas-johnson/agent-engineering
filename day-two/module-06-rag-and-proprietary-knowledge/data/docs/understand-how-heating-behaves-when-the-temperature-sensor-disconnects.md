# Understand how heating behaves when the temperature sensor disconnects

## What happens

If the thermostat's temperature sensor disconnects, the display shows error code E-217. The thermostat turns the heating off to be safe. It cannot reliably measure the room temperature, so it cannot control the heating as usual.

The app shows the same error code and can notify you about it.

## What to do

Contact Dormouse support to arrange a replacement. In the app, go to Help > Contact support.

## While the sensor is disconnected

Heating remains off until the sensor issue is addressed. Do not rely on the thermostat to maintain your target temperature while E-217 is showing. The error is different from a boiler fault: E-217 means the thermostat's temperature sensor is disconnected.

## Check the error code

The display shows an error code when something is wrong. If you need to check the code again, look at the thermostat display or in the app. E-217 indicates a disconnected temperature sensor; the thermostat turns the heating off to be safe.
