# E-221: Humidity sensor fault

## What the code means

E-221 means the thermostat has detected a fault with its humidity sensor. The thermostat's heating continues to work, but humidity readings disappear from the app while the fault is present.

## What causes it

The code indicates a humidity sensor fault. The thermostat does not provide further details about the cause. This fault does not stop the heating from working.

## What to do

1. Check the thermostat display for E-221.
2. Check the app for the same code. The app can also notify you about the error.
3. Allow up to a day for the fault to clear.
4. If E-221 remains after more than a day, contact Dormouse support in the app under Help > Contact support.

## While the fault is present

Your heating keeps working. Humidity readings are unavailable in the app until the fault clears. The error code appears on the thermostat display and in the app while the fault is present.
