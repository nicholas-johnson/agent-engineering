# Set a heating schedule

A schedule sets the target temperature at different times of day. You can create or change schedules in the Dormouse app or the web dashboard.

## Before you start

Choose the day you want to set up. Each day can have up to six periods. A period has a start time and a target temperature, and lasts until the next period starts.

You can set a target temperature from 5 to 30 degrees, in half-degree steps.

## Create or change a day's schedule

1. Open the Schedule tab in the app or web dashboard.
2. Choose a day.
3. Set the start time and target temperature for each period.
4. Save your changes.

Use up to six periods for the day. Set each period's start time and target temperature to match the routine you want.

## Use the same schedule on other days

After setting a day's periods, choose Copy day to use those periods on other days. Choose the days you want to copy the schedule to.

## View today's schedule on the thermostat

On the thermostat, press the dial to open the menu, then choose Menu > Schedule. The thermostat shows today's periods. You can view them there, but you can only change schedule periods in the app or web dashboard.

## How schedule periods work

Each period starts at its set time and continues until the next period starts. The final period continues until the first period of the next day.

The thermostat follows the target temperature for the current period. Warm Wake may be indicated by a sunrise symbol on the display.

## Hand-set temperature changes

If you change the target temperature by hand, the change lasts until the next schedule period starts. After that, the thermostat follows the schedule again.
