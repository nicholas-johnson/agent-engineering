# Thermostat Does Not Respond to Dial Changes

## Check what the dial is changing

When the display shows the room temperature, turning the dial changes the target temperature. The target is shown underneath the room temperature. While you turn the dial, the target temperature gets larger on the display.

The target can be set from 5 to 30 degrees in half-degree steps. If you are looking at the large room-temperature number, check the smaller number underneath it to see the change.

## Check how to turn the dial

Turn the dial to adjust the target temperature. A change made by hand lasts until the next schedule period starts. If the target changes and then changes again later, check the schedule in the app or web dashboard.

## Check what happens when you press the dial

Press the dial to confirm a target temperature change. When the display shows the room temperature, pressing the dial opens the menu.

The menu contains Schedule, Away, Settings and About. Turn the dial to move between these items, then press to choose one.

## Check the display state

The display dims after 20 seconds without a touch. If it has dimmed, touch or turn the dial and check whether the display responds.

If the display is showing a menu item rather than the room temperature, pressing the dial chooses that item. To open the menu, first return to the display showing the room temperature.

## Try the app or web dashboard

You can also change the target temperature in the Dormouse app or web dashboard. If a change made there does not reach the thermostat, check the display for a Wi-Fi symbol with a cross. This symbol means the thermostat is not connected to Wi-Fi.

If the thermostat shows E-110, it cannot reach the Dormouse cloud. It keeps running its schedules, but changes made in the app wait until it reconnects. Check that your router is connected to the internet.

## Check for an error code

When something is wrong, the thermostat displays an error code. The app shows the same code and can notify you about it. Follow the action for the code shown:

| Code | Action |
|---|---|
| E-101 | Check that the router is on and offers a 2.4 GHz network. If the network name or password changed, pair the thermostat again. |
| E-217 | The thermostat turns the heating off to be safe. Contact Dormouse support to arrange a replacement. |
| E-402 | The thermostat is running on backup batteries and cannot switch the heating on. Check whether mains power has been interrupted. |

For another code, follow the instructions in the Error codes section of the user guide.

## Contact Dormouse support

If the display does not respond to turning or pressing the dial, and these checks do not help, contact Dormouse support in the app under Help > Contact support. Include any error code shown on the display.
