# Thermostat Restarts During an Update

## What to expect

Dormouse Thermostat firmware updates are installed automatically between 02:00 and 04:00 local time. Updates cannot be postponed.

During installation, the display shows **UPDATING**. The thermostat then restarts. This usually takes about two minutes, and the heating pauses until the update has finished. The pause is part of the update process.

## While the display shows UPDATING

Leave the thermostat to complete the update. The display may be unavailable for normal temperature control while the thermostat restarts. Do not treat the restart alone as a fault: it is expected during an update.

## After the restart

Once installation is complete, the thermostat resumes operation. The heating pause should end when the update has finished.

If the display shows **E-510**, the update failed. The thermostat keeps its current firmware and tries the update again the next night. Nothing needs to be done for this error.

## If the problem continues

If the thermostat does not resume operation after the update, or you see another error code, check that code in the thermostat user guide. The app shows the same error code as the thermostat and can notify you about it.

For help, contact Dormouse support in the app under Help > Contact support.
