# Firmware 3.4 release notes

## Dormouse Radiator Valve support

Firmware 3.4 adds support for the Dormouse Radiator Valve. Add a valve to a zone in Settings > Home > Add a device. Up to ten valves can join a zone, with each valve heating its radiator to its own temperature.

Valves communicate with their zone's thermostat over a low-power radio link. Only the thermostat uses Wi-Fi.

## Firmware update schedule

Firmware updates now install automatically between 02:00 and 04:00 local time. Previously, updates installed between 01:00 and 05:00.

During an update, the display shows UPDATING. The thermostat restarts, and heating pauses until the update has finished.
