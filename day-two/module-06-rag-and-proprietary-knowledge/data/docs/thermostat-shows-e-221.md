# Thermostat Shows E-221

## What the code means

E-221 means the thermostat has detected a humidity sensor fault. The heating keeps working, but humidity readings disappear from the app.

The thermostat shows the error code on its display. The app shows the same code and can notify you about it if you have error-code notifications turned on.

## Check the humidity readings

Open the app and check the humidity readings for the affected zone. While E-221 is present, those readings are unavailable. This fault does not stop the heating from working.

If the thermostat controls a zone with a Dormouse Room Sensor, check whether humidity readings are missing for that zone too. The code indicates a humidity sensor fault; it does not by itself explain which sensor or component is affected.

## Check the error code

Confirm that the display shows E-221, rather than another error code. If you are checking in the app, compare the code there with the one on the thermostat.

Different codes indicate different faults and may need different action. For example, E-217 means the temperature sensor is disconnected and the thermostat turns the heating off to be safe. Follow the guidance for the code that is actually displayed.

## Understand the effect on heating

E-221 does not turn the heating off. The heating continues to work, but humidity readings disappear from the app while the fault is present.

Do not use the missing humidity readings to assess the humidity in the home. The code concerns the humidity sensor, not the thermostat's heating schedule or target temperature.

## Allow time for the code to clear

If the code remains for less than a day, check the display and app again later. The guide does not specify a reset procedure for E-221, so do not factory reset the thermostat to address this code.

A factory reset removes the Wi-Fi details, schedules and link to your account. It is intended for preparing the thermostat to be given to someone else or left behind when moving house, not for clearing this fault.

## Contact Dormouse support

Contact Dormouse support if E-221 stays on the display for more than a day. You can contact support in the app under Help > Contact support.

When you get in touch, give the support team the error code and say how long it has been showing. Also explain whether humidity readings are missing from the app and confirm that the heating is still working.

## If the display shows a different code

Use the guidance for the code shown on the thermostat. For example:

| Code | Meaning | What to do |
|---|---|---|
| E-217 | Temperature sensor disconnected | The thermostat turns the heating off to be safe. Contact Dormouse support to arrange a replacement. |
| E-110 | Cannot reach the Dormouse cloud | Check that your router is connected to the internet. Schedules continue to run, but app changes wait until the thermostat reconnects. |
| E-401 | Backup batteries low | Replace the two AA backup batteries within a month. |

If the code changes, follow the relevant guidance rather than treating it as E-221.
