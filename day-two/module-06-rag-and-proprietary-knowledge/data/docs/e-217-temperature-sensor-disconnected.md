# E-217: Temperature sensor disconnected

## What E-217 means

E-217 means the thermostat's temperature sensor is disconnected. The thermostat cannot reliably measure the room temperature, so it turns the heating off to be safe.

The display shows E-217 while the fault is present. The app shows the same error code and may notify you if you have enabled error notifications.

## What causes it

E-217 indicates a problem with the connection to the thermostat's temperature sensor. The user guide does not identify a specific cause or provide a user repair for this fault.

## What to do

1. **Check the display.** Confirm that the code shown is E-217.
2. **Check the app.** It shows the same code as the thermostat.
3. **Contact Dormouse support to arrange a replacement.** In the app, go to Help > Contact support.

Do not rely on the thermostat to heat the home while E-217 is showing: it turns the heating off to be safe.

## What to expect while the fault is present

Because the thermostat turns the heating off, it cannot control the heating normally until the sensor fault is resolved. The guide does not specify a temporary override or another user action that restores heating during this error.

## Before contacting support

Have the error code to hand: E-217. If the app also shows it, you can refer to the code there. Contact support through Help > Contact support in the app and ask to arrange a replacement.

## After contacting support

Follow the instructions provided by Dormouse support for arranging the replacement. Once the sensor fault is resolved, check the thermostat display and app to see whether E-217 has cleared. If it remains, contact support again.
