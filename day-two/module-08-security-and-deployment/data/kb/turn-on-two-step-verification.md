# Turn on two-step verification

Two-step verification adds a 6-digit code to your password when you sign in on a new phone or browser. Turn it on in the Dormouse app or web dashboard to add this extra sign-in step to your account.

## Before you start

Sign in to the app or web dashboard with your email address and password. You need access to the method used to receive your sign-in code:

- A code is sent by email.
- If you have set up an authenticator app, you can get the code there instead.

## Enable two-step verification

1. Open **Settings > Account > Two-step verification**.
2. Follow the instructions to turn it on.

The same menu path is available in the app and the web dashboard.

## Sign in with two-step verification

When you sign in on a new phone or browser, enter your password and the 6-digit code. Get the code from your email, or from your authenticator app if you have set one up.

Two-step verification asks for a code when you sign in on a new device or browser. It does not change how you set or use your thermostat's heating settings.
