# Reset your Dormouse account password

If you cannot remember your password, request a reset link from the sign-in screen. The link works for 30 minutes and can only be used once.

## Request a reset link

1. Open the Dormouse app or web dashboard and go to the sign-in screen.
2. Choose **Forgot password?**
3. Enter the email address for your Dormouse account.
4. Follow the instructions in the reset email to set a new password.

## Use the link in time

The reset link expires 30 minutes after it is sent. It can be used only once. If it has expired, or you have already used it, request another link from **Forgot password?** on the sign-in screen.

## Choose a password

Your Dormouse password must have at least 10 characters. Use the new password when you next sign in to the app or web dashboard.
