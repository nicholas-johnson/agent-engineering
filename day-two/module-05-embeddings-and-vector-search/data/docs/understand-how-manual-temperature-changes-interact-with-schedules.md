# Understand how manual temperature changes interact with schedules

## What happens when you change the target temperature

You can set the target temperature by turning the thermostat's dial or using the Dormouse app. A hand-set target temperature stays in effect until the next schedule period starts.

For example, if you change the target temperature during a schedule period, the thermostat uses your new target for the rest of that period. When the next period starts, the schedule sets the target temperature for that period.

## How schedule periods work

A schedule has up to six periods for each day. Each period has a start time and a target temperature. It lasts until the next period starts.

The scheduled temperature therefore does not necessarily change at a fixed interval. It changes when the next period in your schedule begins. If you make a manual change close to that time, it remains in effect only until the period starts.

## Change the temperature by hand

To change the target temperature on the thermostat:

1. Turn the dial until the display shows the target temperature you want.
2. Press the dial to confirm.

You can also change the target temperature in the app. The target can be set from 5 to 30 degrees in half-degree steps.

## Check your schedule

In the app or web dashboard, open the Schedule tab and choose a day to see its periods and start times. A schedule can be different for each day. To use the same periods on other days, choose Copy day.

On the thermostat, choose Menu > Schedule to see today's periods. You can view them there, but you can only change schedules in the app or web dashboard.

## When a schedule resumes

The hand-set target ends when the next schedule period starts. The target then follows that period's scheduled temperature. You do not need to turn the manual change off yourself.

If you want a different target to apply at a later time, you can change the schedule in the app or web dashboard. Otherwise, the next period will use the target temperature already set in the schedule.

## Keep in mind

A manual temperature change is temporary: it applies only until the next schedule period starts. Away mode and boost are separate heating features; this article describes the effect of changing the target temperature by hand.
