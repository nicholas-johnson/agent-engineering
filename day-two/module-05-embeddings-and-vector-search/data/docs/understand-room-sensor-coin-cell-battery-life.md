# Understand Room Sensor coin-cell battery life

## Battery type

A Dormouse Room Sensor uses one CR2032 coin cell. The sensor measures temperature and humidity in another room in its thermostat's zone.

## How long the battery lasts

The CR2032 coin cell typically lasts about a year. Battery life is approximate and can vary with use and conditions.

## How the sensor connects

The Room Sensor communicates with the thermostat for its zone over a low-power 868 MHz radio link. The sensor does not use Wi-Fi; only the thermostat connects to Wi-Fi.

## Using sensors in a zone

A zone can have up to three Dormouse Room Sensors. Each sensor uses its own CR2032 coin cell. To add a sensor, go to Settings > Home > Add a device.
