# Boost Does Not Start

Use this guide when pressing the boost button does not appear to start heating. The boost button is below the thermostat dial.

## Check use of the boost button

Press the boost button once to start a boost. It heats the home at the boost temperature for one hour. The boost temperature is 21 degrees unless it has been changed in Settings > Heating > Boost temperature.

While a boost is running, the display shows an upward arrow. Pressing the boost button again cancels the boost.

## Check the display

Look for the upward arrow after pressing the button. If it is showing, the boost is running; the display may dim after 20 seconds without a touch.

Turn the dial to wake the display and check again. The large number shows the room temperature, with the target temperature underneath.

## Check the target temperature

A boost uses its configured boost temperature, not necessarily the temperature you last set by hand. Check the boost temperature in Settings > Heating > Boost temperature. If it is already set to the temperature you expect, continue with the checks below.

A temperature change made by hand lasts only until the next schedule period starts. The boost, by contrast, runs for one hour unless you cancel it.

## Check for an error code

If the display shows an error code, check its meaning and instructions in the thermostat guide. The app shows the same code and can notify you about it.

For example, E-305 means the boiler is not responding. Check that the boiler is switched on and its pressure is between 1 and 1.5 bar, then check the boiler's display for a fault. For other codes, follow the instructions listed for that code.

## Check mains power

The thermostat needs mains power to switch the heating on. If the display shows E-402, mains power is interrupted. The backup batteries keep the clock and schedules for up to 48 hours, but the thermostat cannot switch on the heating while mains power is off.

Restore mains power, then try the boost button again.

## Check the boiler

If the thermostat shows E-312, the boiler reports a fault of its own. Look up the fault in the boiler's manual, or contact a registered gas engineer.

If there is no error code but the heating still does not start, check that the boiler is switched on and that there is no fault shown on its display.

## Check Wi-Fi only if the app is involved

The thermostat's dial and boost button can be used at the thermostat. If you are trying to start a boost in the app and it does not take effect, check whether the thermostat is connected to Wi-Fi.

If E-110 appears, the thermostat cannot reach the Dormouse cloud. Check that your router is connected to the internet. The thermostat continues to run schedules, but app changes wait until it reconnects.

## Contact support

If the boost still does not start after these checks, contact Dormouse support in the app under Help > Contact support. Include any error code shown on the thermostat.
