# Web dashboard: Schedule screen guide

## Purpose of the Schedule screen

The Schedule screen lets you set the temperatures you want at different times of day. A schedule is made up of periods. Each period has a start time and a target temperature, and lasts until the next period starts.

You can set a schedule in the Dormouse app for Android and iOS, or in the web dashboard. The steps and menu paths are the same in the app and the web dashboard.

Each day can have up to six periods. Choose a day to view or edit its periods. You can also copy one day's periods to other days when you want to use the same schedule on more than one day.

## Open the Schedule screen

Open the Dormouse app or web dashboard and go to the Schedule tab. The screen shows the schedule for a selected day.

To change a day's schedule, select that day and edit its periods. Changes you make to a schedule are used by the thermostat when that day's schedule is in effect.

On the thermostat, Menu > Schedule shows today's periods. You can view them there, but you can only change schedule periods in the app or web dashboard.

## Choose a day

Select the day whose schedule you want to view or change. The screen displays the periods set for that day.

Before editing, check that the selected day is the one you intend to change. Each day can have its own schedule, so changing one day does not automatically change the others.

If several days should use the same periods, edit one day first, then use Copy day to apply its periods to other days.

## Understand schedule periods

A period contains two pieces of information:

- **Start time:** when the period begins.
- **Target temperature:** the temperature the thermostat is set to maintain from that time.

A period continues until the next period starts. The first period of the day therefore remains in effect until the next scheduled period begins.

Each day can have up to six periods. Set periods so their start times and target temperatures reflect the schedule you want for that day.

## Edit periods

Choose a day, then edit the periods shown for it. Set a start time and target temperature for each period you want in that day's schedule.

Keep the limit of six periods per day in mind when changing the schedule. Review the selected day's periods after editing to make sure the start times and target temperatures are as intended.

A schedule sets the target temperature at different times of day. You can also change the target temperature by hand, using the thermostat dial or the app. A manual temperature change lasts until the next schedule period starts.

## Copy periods to other days

Use Copy day when you want another day to use the same periods as the selected day.

1. Select the day whose periods you want to copy.
2. Choose Copy day.
3. Select the other days that should use those periods.
4. Confirm the copy in the app or web dashboard.

Check the schedule for each destination day after copying. Copy day applies the selected day's periods to the days you choose. If you later want different periods for one of those days, select that day and edit its schedule.

## Warm Wake

The thermostat may use Warm Wake with a schedule. The display shows a sunrise symbol when Warm Wake is active. This guide covers choosing a day, editing schedule periods and copying periods to other days.

## Check the schedule on your thermostat

To view today's periods on the thermostat, press the dial to open the menu and choose Menu > Schedule. The thermostat shows today's periods, but schedule changes must be made in the app or web dashboard.

The thermostat display shows the room temperature and target temperature. When you turn the dial, the target temperature becomes larger while you change it. A hand-set target temperature lasts until the next schedule period starts.

## Keep your schedule up to date

Review schedules when your preferred temperatures or daily timings change. Check each day separately if its schedule should differ from the others. Use Copy day for days that should share periods, then edit any day that needs a different schedule.

A schedule can contain up to six periods per day. Each period starts at its set time and lasts until the next period starts.
