# Check the thermostat operating temperature range

## Operating range

The Dormouse Thermostat is designed for indoor use between 0 and 40 degrees. This is the temperature range in which the thermostat is specified to operate.

## Check the room temperature

The thermostat's display shows the room temperature in large numbers. Compare that reading with the indoor operating range: the room should be at least 0 degrees and no more than 40 degrees.

## If the room is outside the range

Move the thermostat to an indoor location within the 0 to 40 degree range. The thermostat is not designed for use outside that range.

## About the temperature reading

The thermostat measures temperature with an accuracy of 0.3 degrees. A reading close to either end of the operating range may therefore differ slightly from the actual room temperature.
