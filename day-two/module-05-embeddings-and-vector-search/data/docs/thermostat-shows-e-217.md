# Thermostat Shows E-217

## What E-217 means

E-217 means the thermostat's temperature sensor is disconnected. The thermostat cannot reliably measure the room temperature, so it turns the heating off to be safe.

The code appears on the thermostat display. The app shows the same code and may send a notification if notifications for errors are enabled.

## Identify the condition

Check the thermostat display for E-217. If you use the app, check the thermostat's status there too. This code identifies a disconnected temperature sensor; it is different from an issue with the Wi-Fi connection or the boiler.

While E-217 is present, the thermostat has turned the heating off. Do not rely on it to control the heating until the sensor issue has been resolved.

## What to do

Contact Dormouse support to arrange a replacement. In the app, go to Help > Contact support.

Tell support that the thermostat displays E-217. Include any other information the app shows about the error, if available. Do not try to fix the sensor by changing schedules, adjusting the target temperature or resetting the thermostat.

## While the error is present

The thermostat will not switch on the heating while E-217 is active, because it cannot measure the temperature safely. Changing the temperature in the app or on the thermostat does not resolve the disconnected sensor condition.

If your home needs heat while you arrange a replacement, use the boiler or heating system only in the way described in its own instructions. For help with the boiler itself, follow its manual or contact a registered gas engineer.

## After contacting support

Follow the instructions from Dormouse support to arrange a replacement. If E-217 remains on the display, continue to treat the heating as unavailable through the thermostat. Do not assume that the heating has resumed until the error has cleared and the thermostat is operating normally.

If a different error code appears, refer to that code's guidance.
