# Resolve error E-101: Wi-Fi network not found

## What E-101 means

E-101 means the thermostat cannot find its Wi-Fi network. The thermostat needs a 2.4 GHz Wi-Fi network to connect. It cannot join a 5 GHz network.

Check that your router is switched on and that its Wi-Fi network is available on 2.4 GHz. If you have changed the network name or password since pairing the thermostat, pair it again with the updated network details.

## Check that your router is on

Make sure the router is switched on and appears to be working. If it has lost power or stopped working, restore its power and wait for its Wi-Fi network to become available.

Then check whether the network the thermostat should use is available on 2.4 GHz. If the network is only available on 5 GHz, the thermostat cannot connect to it.

## Check for a 2.4 GHz network

Some routers provide both 2.4 GHz and 5 GHz Wi-Fi. Check your router's settings or instructions to confirm that 2.4 GHz Wi-Fi is enabled and available.

If your router shows separate network names for each band, make sure the network you intend to use is the 2.4 GHz one. The thermostat cannot join the 5 GHz network. If you are unsure which network is 2.4 GHz, check the router's instructions or settings.

## Pair the thermostat again if network details changed

Pair the thermostat again if you changed the Wi-Fi network's name or password. Pairing connects the thermostat to your Wi-Fi and Dormouse account.

1. Hold the thermostat dial down for 5 seconds, until the display shows PAIR.
2. In the Dormouse app, choose Add thermostat and follow the steps.
3. Keep your phone within 5 metres of the thermostat until the app says pairing has finished.

Pairing must finish within 3 minutes of PAIR appearing. If it takes longer, the thermostat shows E-104. Hold the dial down for 5 seconds to start pairing again.

## Check the connection

After pairing, wait for the app to confirm that it has finished. If E-101 appears again, check that the router is on and that the 2.4 GHz network is still available.

For help, contact Dormouse support in the app under Help > Contact support.
