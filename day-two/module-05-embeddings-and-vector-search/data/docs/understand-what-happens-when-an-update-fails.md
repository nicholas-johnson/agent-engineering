# Understand what happens when an update fails

## What happens during an update

The Dormouse Thermostat installs firmware updates automatically between 02:00 and 04:00 local time. You cannot postpone an update.

While an update installs, the display shows **UPDATING** and the thermostat restarts. Installation takes about two minutes. The heating pauses until the update has finished.

## How to tell if an update failed

If an update fails, the thermostat display shows **E-510**. The app shows the same error code and can notify you if you have error-code notifications turned on.

## What happens next

The thermostat keeps its current firmware. It does not install a partial update, and it continues using the firmware already on the thermostat.

The thermostat tries to install the update again the next night. You do not need to start the update yourself or reset the thermostat.

## What you need to do

There is nothing you need to do for E-510. Leave the thermostat powered on so it can try again during the next update window.

If E-510 appears again after another update attempt, the thermostat will keep its current firmware and try again the following night.

## If you see a different error

Other error codes have different causes and actions. Check the code shown on the thermostat in the Error codes section of the user guide. You can contact Dormouse support in the app under Help > Contact support.
