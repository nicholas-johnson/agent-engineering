# Understand how schedule periods work

## What a schedule does

A schedule tells your Dormouse Thermostat what target temperature to use at different times of day. You set it in the Schedule tab of the Dormouse app or web dashboard.

A schedule is made up of periods. Each period sets a start time and a target temperature. When a period starts, the thermostat uses its target temperature. That temperature remains in effect until the next period starts.

## How periods fit together

Each period applies from its start time up to, but not including, the start time of the next period. For example, if one period starts at 07:00 and the next starts at 09:00, the first period's temperature applies from 07:00 until 09:00.

The final period of the day continues until the next scheduled period begins. Your schedule can have up to six periods per day.

| Period | Start time | Target temperature applies |
|---|---:|---|
| First | 07:00 | From 07:00 until the next period starts |
| Next | 09:00 | From 09:00 until the following period starts |

The times and temperatures in this example are illustrative.

## Set or change a period

1. Open the Schedule tab in the app or web dashboard.
2. Choose the day you want to edit.
3. Set a start time and target temperature for each period you need.
4. Save your changes if prompted.

You can set up to six periods for each day. On the thermostat, choose Menu > Schedule to see today's periods. You can view them there, but you must use the app or web dashboard to change them.

## Use the same periods on other days

If you want another day to use the same periods, choose Copy day in the Schedule tab. This copies that day's periods to the day or days you select.

Check the copied schedule to make sure its start times and target temperatures suit those days. Each day can have its own schedule.

## What happens when you change the temperature by hand

If you change the target temperature by turning the thermostat dial or using the app, that manual change lasts until the next schedule period starts. When the next period begins, the thermostat uses the target temperature set for that period.

This means a manual change does not replace the schedule. To change the temperature for a period each time it starts, edit that period in the Schedule tab.

## Warm Wake

Warm Wake is a thermostat feature associated with schedule periods. You may see its sunrise symbol on the display. For information about the schedule periods themselves, use the Schedule tab in the app or web dashboard.
