# Firmware 4.1 release notes

## Boost temperature

You can now change the boost temperature in Settings > Heating > Boost temperature. Previously, the boost temperature was fixed at 21 degrees.

## Password reset links

Password reset links now work for 30 minutes. Previously, they worked for 24 hours.
