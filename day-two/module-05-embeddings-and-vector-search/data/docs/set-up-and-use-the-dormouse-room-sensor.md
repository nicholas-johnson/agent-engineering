# Set up and use the Dormouse Room Sensor

## What the sensor measures

The Dormouse Room Sensor measures temperature and humidity in a room. It can join a zone so that the zone's thermostat can use measurements from another room.

The sensor has one CR2032 coin cell battery, which lasts about a year. Replace the battery when needed to keep the sensor working.

## Add the sensor to a zone

Add the sensor in the Dormouse app or web dashboard:

1. Go to Settings > Home > Add a device.
2. Follow the instructions to add the Dormouse Room Sensor to a zone.

The sensor communicates with that zone's thermostat over a low-power 868 MHz radio link. Only the thermostat uses Wi-Fi.

## How many sensors you can add

You can add up to three Dormouse Room Sensors to each zone. A home can have up to four Dormouse Thermostats, each controlling its own zone. The sensor limit applies separately to each zone.
