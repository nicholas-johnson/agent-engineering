# Room Sensor Does Not Join a Zone

## Check how you are adding the sensor

Add a Dormouse Room Sensor from the app or web dashboard:

1. Open Settings > Home > Add a device.
2. Follow the on-screen steps to add the sensor to a zone.

A Room Sensor does not join a zone through the thermostat's Schedule or Settings menus. If you started elsewhere, return to Settings > Home > Add a device and try again.

## Check the zone's sensor limit

A zone can have up to three Dormouse Room Sensors. If the zone already has three, another sensor cannot join it.

Check which sensors are assigned to the zone. If it has reached the limit, choose a different zone for the new sensor, or remove a sensor from the existing zone before trying again. A home can have multiple zones, each controlled by its own Dormouse Thermostat.

## Check that the device is a Dormouse Room Sensor

Only a Dormouse Room Sensor can join a Dormouse zone as a room sensor. It measures temperature and humidity in another room of the zone. A Dormouse Radiator Valve is a separate device and joins a zone to control a radiator.

## Understand how the sensor connects

Room Sensors communicate with the thermostat for their zone over a low-power 868 MHz radio link. Only the thermostat uses Wi-Fi. The sensor does not join your Wi-Fi network, so changing Wi-Fi details will not help with adding the sensor to a zone.

## Try adding it again

After confirming that you are using Settings > Home > Add a device and that the zone has fewer than three sensors, follow the app or web dashboard steps again. Make sure you select the intended zone when prompted.

If the sensor still does not join, contact Dormouse support in the app under Help > Contact support.
