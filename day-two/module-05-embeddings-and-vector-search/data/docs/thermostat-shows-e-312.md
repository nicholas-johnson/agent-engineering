# Thermostat Shows E-312

## What the code means

E-312 means the boiler has reported a fault of its own. The thermostat is showing the code reported by the boiler; it does not identify the boiler fault.

## What to do

1. Check the boiler's own display for its fault code or message.
2. Look up that fault in the boiler's manual.
3. If you cannot resolve it by following the manual, contact a registered gas engineer.

For help with the thermostat, contact Dormouse support in the app under Help > Contact support.
