# Room Sensor Humidity Readings Are Missing

## What this guide covers

Use this guide when humidity readings from a Dormouse Room Sensor are missing from the app. A Room Sensor measures temperature and humidity and joins a thermostat's zone. The sensor communicates with that zone's thermostat over a low-power radio link; only the thermostat uses Wi-Fi.

This guide covers the thermostat's E-221 humidity sensor fault. Check the thermostat display or the app for the code. If E-221 is shown, the thermostat's humidity sensor has a fault. The heating continues to work, but humidity readings disappear from the app.

## Check for E-221

Look at the thermostat display for an error code, or check the app. The app shows the same code as the thermostat and can notify you about it.

If the code is E-221, the heating keeps working. The fault affects humidity readings: they disappear from the app. Contact Dormouse support if E-221 stays on the display for more than a day.

## Contact Dormouse support

If E-221 remains after more than a day, contact support in the app under Help > Contact support. Include the error code and say how long it has been showing.

Until the fault is resolved, the heating continues to work, but humidity readings are unavailable in the app.
