# Resolve error E-510: Firmware update failed

## What E-510 means

E-510 means a firmware update failed to install. The thermostat keeps running its current firmware and tries to install the update again the following night.

You do not need to restart the thermostat, change its settings or pair it again. The error does not mean that the thermostat has lost its schedules or account connection.

## What happens while you wait

Firmware updates install automatically between 02:00 and 04:00 local time. During an installation, the display shows UPDATING and the thermostat restarts. This takes about two minutes, and heating pauses until the update has finished.

After a failed update, the thermostat continues using its current firmware and makes another attempt the next night. E-510 does not require you to postpone or manually start an update.

## What to do

1. Leave the thermostat powered and connected as usual.
2. Allow it to try again during the next automatic update period.
3. If the display still shows E-510 after the next night, allow the thermostat to make another automatic attempt.

The thermostat retains its current firmware if an update fails. There is no need to factory reset it or change your Wi-Fi details.

## When to contact support

If E-510 continues to appear after repeated nightly attempts, contact Dormouse support in the app under Help > Contact support. Include the error code and explain that the thermostat has had more than one overnight retry.
