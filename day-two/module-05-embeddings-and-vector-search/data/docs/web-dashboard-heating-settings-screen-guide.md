# Web dashboard: Heating settings screen guide

## About this guide

This guide explains two heating settings in the Dormouse web dashboard: the boost temperature and the duration of a manual target-temperature change.

The Dormouse Thermostat works with the Dormouse app for Android and iOS, and with the web dashboard. Most settings can be changed in any of them. The setting paths in this guide, such as Settings > Heating > Boost temperature, are the same in the app and the web dashboard.

The instructions apply to the Dormouse Thermostat with firmware 4.1. To check the firmware version, press the thermostat dial to open the menu, then choose Menu > About.

## Open the heating settings

Sign in to the web dashboard and open Settings > Heating. Use this area to change the boost temperature.

A boost heats the home at the boost temperature for one hour. The boost temperature is the target used while the boost is running; changing it does not change the target temperature for other heating periods.

You can also set the target temperature manually from the thermostat or the app. A manual change has a different duration from a boost: it lasts until the next schedule period starts.

## Change the boost temperature

The boost temperature is 21 degrees unless you change it. To choose a different boost temperature, open Settings > Heating > Boost temperature and set the temperature you want.

The thermostat's target temperature can be set from 5 to 30 degrees, in half-degree steps. Use this range when choosing a target.

The boost temperature applies when you start a boost. It does not alter your schedule or the away temperature. To change the away temperature, go to Settings > Away > Away temperature.

## Start and cancel a boost

Press the boost button below the thermostat dial to start a boost. The heating runs at the boost temperature for one hour. While the boost is running, the display shows an upward arrow.

Press the boost button again to cancel the boost before the hour is up.

Changing the boost temperature in Settings > Heating > Boost temperature sets the temperature used for boosts. The boost button starts or cancels the boost; it does not open the heating settings.

## Manual target-temperature changes

To change the target temperature manually, turn the thermostat dial or use the app. A manual change lasts until the next schedule period starts.

For example, if you raise the target temperature between two scheduled periods, the manually selected target remains in effect until the next period begins. At that point, the schedule sets the target for the new period.

A manual target-temperature change is not the same as a boost. A manual change remains until the next schedule period starts. A boost runs at the boost temperature for one hour, unless you cancel it sooner.

## Schedules and heating periods

A schedule sets the target temperature at different times of day. Each day can have up to six periods. Each period has a start time and a target temperature, and lasts until the next period starts.

You can view and change schedules in the Schedule tab of the web dashboard or app. On the thermostat, Menu > Schedule shows today's periods, but schedules can only be changed in the app or web dashboard.

Because manual changes last until the next schedule period starts, the next period determines when the scheduled target takes over from a manual target.

## Quick reference

| Heating action or setting | What it does |
|---|---|
| Boost temperature | Sets the target used while a boost is running. It is 21 degrees by default. |
| Start a boost | Heats at the boost temperature for one hour. |
| Cancel a boost | Press the boost button again while the boost is running. |
| Manual target-temperature change | Lasts until the next schedule period starts. |
| Schedule period | Sets its target from its start time until the next period starts. |

## Related heating behaviour

Frost protection is always on and cannot be turned off. If the room falls below 5 degrees, the thermostat turns the heating on, even when the heating is off or away mode is on. The display shows a snowflake while frost protection is heating.

Away mode keeps the home at the away temperature until you turn it off. Its default temperature is 16 degrees. Change it in Settings > Away > Away temperature.

Warm Wake is a thermostat feature. The display shows a sunrise symbol when Warm Wake is active.

## If the thermostat shows an error

When the thermostat detects a problem, it shows an error code. The app shows the same code and can notify you about it. Check the error-code table in the user guide for what the code means and what to do.

For example, E-110 means the thermostat cannot reach the Dormouse cloud. The thermostat keeps running its schedules, and changes made in the app wait until it reconnects.

For help, open Help > Contact support in the app.
