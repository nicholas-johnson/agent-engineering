# Heating Does Not Start When the Boiler Is Not Responding

## What the error means

If the thermostat shows error code E-305, it cannot get a response from the boiler. The thermostat may be asking for heat, but the boiler is not responding. Check the boiler itself before changing thermostat settings.

The app shows the same error code as the thermostat. If you have notifications enabled, it can also notify you when an error occurs.

## Check that the boiler is switched on

Check that the boiler is switched on. If it is off, switch it on and allow it time to respond to a heating request. Then check whether the thermostat still shows E-305 and whether the heating starts.

## Check the boiler pressure

Check the pressure shown on the boiler. It should be between 1 and 1.5 bar.

If the pressure is outside this range, follow the boiler's own instructions for checking or correcting it. Do not guess at a procedure: boiler controls and instructions can vary. Once the pressure is within range, check whether the boiler responds to the thermostat.

## Check the boiler display for a fault

Look at the boiler's display for a fault code or message. If it reports a fault, consult the boiler's manual for what that fault means. If the boiler reports that it has found a fault of its own, contact a registered gas engineer.

## If the thermostat still shows E-305

If the boiler is on, its pressure is between 1 and 1.5 bar, and its display does not show a fault, but E-305 remains, contact Dormouse support in the app under Help > Contact support. Include the error code and the checks you have made.

## If a different error appears

If the thermostat shows a different code, follow the guidance for that code rather than the E-305 checks. For example, E-312 means the boiler reports a fault: look up the fault in the boiler's manual or contact a registered gas engineer.

## Heating and safety

Do not open the thermostat or attempt to repair the boiler yourself. If the thermostat shows E-217, it turns the heating off to be safe; contact Dormouse support to arrange a replacement.
