# Resolve error E-312: Boiler reports a fault

## What E-312 means

E-312 means the boiler has reported a fault of its own. The thermostat displays the code when it receives that report. It does not identify the cause of the boiler fault; check the boiler's own display for its fault code or message.

## Check the boiler's display

Look at the boiler's display and note any fault code or message shown there. Use the boiler's own manual to look up what that code means and what action it recommends.

The thermostat's E-312 code is not a substitute for the boiler's fault information. The boiler manual is the right reference for interpreting a fault reported by the boiler.

## When to call a registered gas engineer

If the boiler's manual says the fault needs professional attention, or you cannot resolve it using the manual's instructions, contact a registered gas engineer. Follow the boiler manual's safety instructions while the fault is present.

## If the boiler shows E-312 again

If the boiler continues to report a fault after you have followed the manual's instructions, consult the manual again or contact a registered gas engineer. The thermostat cannot diagnose or clear a fault within the boiler.
