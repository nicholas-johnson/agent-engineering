# Use a password reset link

Use a password reset link if you cannot remember your Dormouse account password. You can request one from the sign-in screen in the Dormouse app or web dashboard.

## Request a reset link

1. On the sign-in screen, choose **Forgot password?**
2. Enter the email address for your Dormouse account.
3. Follow the link sent to that address to reset your password.

## Use the link in time

A reset link works for 30 minutes from when it is sent. It can only be used once. If it has expired or you have already used it, request another link from the sign-in screen by choosing **Forgot password?** and entering your email address again.
