# Understand how heating behaves when the humidity sensor has a fault

## What the fault means

If the thermostat detects a humidity sensor fault, it shows error code E-221. The app shows the same code. Humidity readings disappear from the app while the fault is present.

The fault affects humidity readings, not the heating. Heating continues to work.

## What to expect

- The thermostat continues controlling the heating.
- Humidity readings are unavailable in the app.
- The thermostat displays E-221.
- You may receive an app notification if you have enabled notifications for thermostat errors.

## What to do

If E-221 appears, the heating can continue running as usual. Contact Dormouse support if the code remains for more than a day. In the app, go to Help > Contact support.

## Error-code summary

| Code | Meaning | Effect on heating |
|---|---|---|
| E-221 | Humidity sensor fault | Heating continues; humidity readings disappear from the app. |
