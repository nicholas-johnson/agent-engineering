# Firmware 3.1 release notes

## Geofencing for away mode

Geofencing can turn away mode on and off using the location of household members' phones.

Away mode turns on when every household member who shares their location is more than 1 km from home. It turns off when the first of them comes back within 1 km.

Each member chooses whether to share their location in the app. To stop geofencing for the whole home, go to Settings > Away > Geofencing.

## Away temperature

You can now change the temperature used while away mode is on. The default is 16 degrees. Change it in Settings > Away > Away temperature.
