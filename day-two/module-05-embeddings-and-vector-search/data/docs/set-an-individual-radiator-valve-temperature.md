# Set an individual radiator valve temperature

A Dormouse Radiator Valve controls the temperature of the radiator it is fitted to. When it joins a zone, you can set its own target temperature independently of the zone thermostat and other radiator valves in that zone.

## How individual temperatures work

Each Dormouse Radiator Valve heats its radiator towards its own target temperature. This lets you set different temperatures for different radiators in the same zone.

For example, you can set a warmer target for one room and a cooler target for another. The zone thermostat continues to control its own heating according to its target and schedule; a radiator valve's temperature setting applies to the radiator it controls.

A home can have up to four thermostats, each controlling its own zone. Up to ten Dormouse Radiator Valves can join a zone.

## Before you set a temperature

The radiator valve must be added to the zone whose thermostat it will use. To add it, go to Settings > Home > Add a device.

The valve communicates with its zone's thermostat over a low-power radio link. It does not connect directly to Wi-Fi. Only the thermostat uses Wi-Fi.

The Dormouse Radiator Valve fits M30 x 1.5 valve bodies. Adapters are included for other common valve types. It runs on two AA batteries, which last about two years.

## Set the valve temperature

1. Open the Dormouse app or web dashboard.
2. Find the radiator valve in its zone.
3. Choose the temperature you want for that valve.

The valve then controls its radiator to its own target temperature. Repeat for other valves if you want different temperatures in other rooms.

## The thermostat and valve have separate targets

A valve's target temperature is for its own radiator. It does not change the thermostat's target, the zone schedule or the targets of other valves.

Set the thermostat's target or schedule separately if you want to change the temperature controlled by the thermostat. The thermostat's schedule applies to the thermostat; a valve's individual temperature setting applies to its radiator.

## Check the zone

If the valve is not listed, make sure it has been added to the intended zone in Settings > Home > Add a device. Each valve must be assigned to a zone so it can communicate with that zone's thermostat.

If the thermostat is not connected to Wi-Fi, it cannot receive changes from the app or web dashboard until it reconnects. When it reconnects, changes made in the app wait until then.

## Temperature control and limits

The thermostat's target temperature can be set from 5 to 30 degrees in half-degree steps. These limits are documented for the thermostat; the guide does not specify a separate temperature range or adjustment steps for the Dormouse Radiator Valve.

A valve controls the radiator it is fitted to. It does not replace the thermostat or control another zone's heating.
