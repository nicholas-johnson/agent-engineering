# Schedule Periods Are Missing

Use this guide when a schedule does not show the periods you expect. Schedules can be viewed in the Dormouse app or web dashboard. On the thermostat, Menu > Schedule shows today's periods.

## Check the selected day

Schedules are organised by day. In the Schedule tab, check that you have selected the day whose periods you want to view. If you are looking at the thermostat, remember that Menu > Schedule shows today's periods only.

Each day can have its own schedule, so periods set for one day do not automatically appear on other days. If the selected day is correct but some periods are still missing, check how many periods that day already has.

## Check the daily period limit

A day can have up to six periods. Each period has a start time and a target temperature, and lasts until the next period starts. If a day already has six periods, it cannot have another one.

Review the selected day's periods in the Schedule tab in the app or web dashboard. Check their start times and target temperatures, and decide whether the periods you need are already represented. The thermostat can show today's periods, but schedules can only be changed in the app or web dashboard.

## Copy periods to other days

Periods are set separately for each day. To use the same periods on more than one day, open the Schedule tab in the app or web dashboard, choose the day that has the periods you want, and choose Copy day. Select the other days that should use those periods.

Copying a day is useful when several days should follow the same schedule. Check each destination day afterwards to confirm it has the periods you expect. A day can still have no more than six periods.

## Change or review a schedule

To review or change a schedule, open the Schedule tab in the app or web dashboard and choose a day. Each period has a start time and target temperature. The period remains in effect until the next one starts.

The thermostat's Menu > Schedule view is for today's periods; it does not let you change them. Use the app or web dashboard to make schedule changes.

## Check that the change has taken effect

After making a change or copying periods, return to the Schedule tab and select each relevant day. Confirm that the periods appear on the intended days and that no day has more than six.

If the thermostat is not connected to the Dormouse cloud, changes made in the app wait until it reconnects. If the display shows E-110, check that your router is connected to the internet. The thermostat keeps running its schedules while it cannot reach the cloud.
