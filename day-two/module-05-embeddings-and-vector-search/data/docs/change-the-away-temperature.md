# Change the away temperature

Away mode keeps your home at a set temperature until you turn it off. The away temperature is 16 degrees by default. You can change it in the Dormouse app or the web dashboard.

## Change the temperature

1. Open the Dormouse app or web dashboard.
2. Go to Settings > Away > Away temperature.
3. Set the temperature you want.

The new temperature is used while away mode is on.

## Turn away mode on

To use the away temperature, turn on away mode in the app, or choose Menu > Away on the thermostat. You can also use geofencing to turn away mode on and off automatically, based on household members' locations.

Frost protection remains active in away mode. If the room falls below 5 degrees, the thermostat turns on the heating to help stop pipes freezing.
