# Thermostat Shows the Wi-Fi Cross

## What the symbol means

A Wi-Fi symbol with a cross means the thermostat is not connected to Wi-Fi. This is different from a cloud connection error: in that case, the thermostat cannot reach the Dormouse cloud, but it may still be connected to Wi-Fi.

Check the error code on the thermostat display or in the app. The app shows the same code as the thermostat and can notify you when an error occurs.

## Check the connection status

Look at the display for an error code as well as the Wi-Fi symbol.

- **E-101** means the thermostat cannot find the Wi-Fi network.
- **E-110** means the thermostat cannot reach the Dormouse cloud. The router may still be connected to the thermostat; the issue is reaching the internet or Dormouse cloud.
- If there is no error code, check whether the Wi-Fi cross is still showing. The cross indicates that the thermostat is not connected to Wi-Fi.

The thermostat's Wi-Fi connection is separate from the low-power radio link used by Dormouse Radiator Valves and Room Sensors. Those devices communicate with their zone's thermostat, not directly over Wi-Fi.

## If the display shows E-101

E-101 means the Wi-Fi network was not found. Check that your router is switched on and offers a 2.4 GHz network. The thermostat cannot join a 5 GHz network.

If you have changed the Wi-Fi network name or password, pair the thermostat again so it can join the network with the updated details. Pairing also connects the thermostat to your Dormouse account.

To pair again:

1. Hold the thermostat dial down for 5 seconds, until the display shows PAIR.
2. In the app, choose Add thermostat and follow the steps.
3. Keep your phone within 5 metres of the thermostat until the app says pairing has finished.

Pairing must finish within 3 minutes of PAIR appearing. If it takes longer, the display shows E-104. Hold the dial for 5 seconds and start again.

## If the display shows E-110

E-110 means the thermostat cannot reach the Dormouse cloud. Check that your router is connected to the internet.

While the thermostat is unable to reach the cloud, it continues running its schedules. Changes made in the app wait until the thermostat reconnects. This is not the same as E-101: E-101 indicates that the Wi-Fi network was not found, while E-110 indicates a cloud connection problem.

## If you have changed Wi-Fi details

When the network name or password changes, the thermostat needs to be paired again to connect using the new details.

Before starting, make sure the router is on and that the network is 2.4 GHz. Then start pairing on the thermostat and complete the steps in the app within 3 minutes. Keep your phone within 5 metres of the thermostat throughout pairing.

If pairing times out, E-104 appears. Start again by holding the dial down for 5 seconds, until the display shows PAIR.

## Check whether heating continues

A lost cloud connection does not stop the thermostat running its schedules. If E-110 is displayed, the thermostat keeps running them, but app changes wait until the connection is restored.

If the thermostat has no mains power, it cannot switch the heating on. Its backup batteries keep the clock and schedules for up to 48 hours, but do not provide power for heating. E-402 indicates that mains power has been interrupted.

## Get support

If the thermostat still shows a Wi-Fi cross or an error after you have checked the network and followed the relevant steps, contact Dormouse support in the app under Help > Contact support. Include the error code shown on the thermostat or in the app.
