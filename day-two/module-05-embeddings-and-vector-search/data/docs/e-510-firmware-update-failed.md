# E-510: Firmware update failed

## What E-510 means

E-510 means a firmware update failed to install. The thermostat keeps running its current firmware and tries to install the update again the next night.

Firmware updates install automatically between 02:00 and 04:00 local time. While an update is installing, the display shows UPDATING and the thermostat restarts. The heating pauses during the update, which takes about two minutes.

## What can cause the error

E-510 means the update did not complete successfully. The error code does not identify a specific cause. No action is needed to diagnose or correct the failure: the thermostat keeps its current firmware and automatically tries again the next night.

## What to do

Follow these steps:

1. Note that the display shows E-510. The app also shows the same error code.
2. Leave the thermostat powered on. It continues to use its current firmware.
3. Wait for the thermostat to try the update again the next night.
4. If the update fails again, the thermostat keeps its current firmware and tries again the following night.

There is no manual update procedure to start and no need to change your settings.

## What to expect during the next attempt

The thermostat installs updates automatically between 02:00 and 04:00 local time. During the attempt, the display shows UPDATING, then the thermostat restarts. The heating pauses until the update has finished. This takes about two minutes.

If the update succeeds, the thermostat resumes operation with the installed firmware. If it fails, E-510 appears and the thermostat retains its current firmware until another attempt.

## Your schedules and settings

An E-510 failure does not remove your schedules or reset the thermostat. The thermostat keeps running its current firmware, with your existing schedules and settings.

The error code is also available in the app, where you can receive notifications about thermostat errors if you have enabled them in Settings > Notifications.

## If the code remains

No action is needed when E-510 appears: the thermostat retries automatically the next night. Keep the thermostat powered on so it can make another attempt.

If you need help, contact support in the app under Help > Contact support.
