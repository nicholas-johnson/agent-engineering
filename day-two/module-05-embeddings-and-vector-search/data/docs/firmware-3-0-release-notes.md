# Firmware 3.0 release notes

## Release date

20 January 2025

## Changes

### Two-step verification

You can now turn on two-step verification for your account. When you sign in on a new phone or browser, you will need your password and a 6-digit code. The code is sent by email, or provided by an authenticator app if you have set one up.

To turn on two-step verification, go to Settings > Account > Two-step verification.

### More thermostats per home

A home can now have up to four Dormouse Thermostats. Previously, a home could have up to two. Each thermostat controls its own zone with its own schedule.
