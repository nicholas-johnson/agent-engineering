# Copy schedule periods to another day

Use **Copy day** in the Dormouse app or web dashboard to apply one day's schedule periods to other days. This is useful when you want several days to use the same set of periods.

## Before you start

Each day can have up to six schedule periods. Every period has a start time and a target temperature, and lasts until the next period starts.

You can edit schedules in the app or web dashboard. On the thermostat, **Menu > Schedule** shows today's periods, but you cannot change them there.

## Copy a day's periods

1. Open the **Schedule** tab in the app or web dashboard.
2. Choose the day whose periods you want to use.
3. Choose **Copy day**.
4. Select the other days that should use those periods.
5. Confirm the copy.

The selected days will use the copied day's schedule periods. Choose the source day carefully: it is the day whose periods you want to apply elsewhere.

## Check the schedule

After copying, open each destination day in the Schedule tab and check its periods. Confirm that the start times and target temperatures are right for the days selected.

The thermostat follows the schedule for each day. A period's target temperature applies from its start time until the next period starts.

## Make further changes

To adjust a day after copying, select it in the Schedule tab and edit its periods there. You can also choose a different source day and use **Copy day** again to apply that day's periods to other days.
