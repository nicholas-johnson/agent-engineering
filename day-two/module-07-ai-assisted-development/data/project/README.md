# Dormouse dashboard

A small stand-in for the Dormouse web dashboard's code: the settings, when Warm Wake switches the heating on, and the settings page. The AI tools in this module work on it.

```bash
python -m unittest
python -m dormouse homes/flat-3b.json
```

The second command says when Warm Wake switches the heating on for one saved home in `homes/`, and writes that home's settings page next to it.

`AGENTS.md` tells coding agents how to work here. Codex, Cursor, Copilot and others read it; `CLAUDE.md` points Claude Code at it.
