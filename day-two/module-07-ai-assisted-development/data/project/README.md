# Dormouse dashboard

A small stand-in for the Dormouse web dashboard's code: the settings, when Warm Wake switches the heating on, and the settings page. The coding agents in this module change it.

```bash
python -m unittest
```

`AGENTS.md` tells coding agents how to work here. Codex, Cursor, Copilot and others read it; `CLAUDE.md` points Claude Code at it.
