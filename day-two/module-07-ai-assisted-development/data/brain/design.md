# Design

How the app and the web dashboard look. Prototypes should look like this too.

## Colours

- Background: cream, #FBF7F0
- Text and headings: night blue, #1E2A44
- Accent, for selected choices and buttons: ember orange, #E8743B
- Lines between rows: #E6DFD3

## Type

- System font (-apple-system, Segoe UI, Roboto, sans-serif).
- Page heading 28 px, section headings 18 px bold, body 16 px.

## Settings screens

- A settings screen is a list of sections, each with a heading: Heating, Schedule, Away.
- Each setting is a row: its name, a one-line explanation underneath in grey, and the control on the right.
- On and off settings use a switch.
- A choice of three or fewer uses a segmented control: the options side by side, the chosen one filled in ember orange.
- Changes save as soon as they are made. There is no Save button.
- When a setting depends on another, it appears only while that setting is on.
